# HarshiGlow Yoga & Wellness ✨

A modern, responsive web application for **HarshiGlow Yoga & Wellness** with Yogini Harshu. Built with **React**, **Vite**, and **Tailwind CSS**.

---

## 🧘 Key Features

- 🌟 **Hero & Brand Narrative**: Engaging introduction to Yogini Harshu and mindful movement philosophy.
- 📱 **Mobile-First Instagram Reels**: Touch-swipeable carousel, category filters, interactive likes/views, and an authentic reel player modal.
- 🌿 **Membership Batches & Pricing**: Standard, Intensive, and VIP 1-on-1 tiers.
- 📅 **Interactive 3-Step Enrollment**: Plan selection, batch timing & mode (Zoom Live vs In-Studio Offline), learner notes, and promo coupon system (`HARSHI25`).
- 💬 **Direct WhatsApp Integration**: Instant booking confirmation and UPI payment request generation via WhatsApp.
- 📱 **Fully Responsive**: Designed with mobile-first aesthetics, bottom drawer navigation, and zero horizontal overflows.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React + Custom SVGs
- **Typography**: Playfair Display (Serif) & Plus Jakarta Sans (Sans-serif)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Dev Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
